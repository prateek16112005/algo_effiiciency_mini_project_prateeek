# Delivery Route Optimization — Recurrence, Greedy, DP, Graphs, and TSP

## Overview
This project demonstrates a mix of algorithmic strategies applied to an e-commerce delivery route optimization micro-project:
- Recurrence-based route cost estimation
- Greedy (0/1 knapsack) for parcel selection by value/weight ratio
- Dynamic programming ideas for small DP-based TSP (Held–Karp)
- Graph algorithms: Dijkstra shortest path and Prim MST
- TSP solutions: brute-force and Held–Karp to highlight intractability
- Visualizations: route map, Gantt-like schedule, profit vs weight

## Structure
- `delivery_route_optimization.py` — main script / notebook code (well-commented).
- `requirements.txt` — Python dependencies.
